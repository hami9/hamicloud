## 1. Acceptance Criteria & Checklist

### Architecture Decision Records
- [x] **ADR-0001 Responsibility Split:** States which decisions belong to the FastAPI control API, the Go scheduler, the Go execution workers, and Kubernetes.
  - Answers in one sentence: *who decides that a job is allowed to start right now?* (The Go Scheduler via `ExecutionIntent`).
  - States that HamiCloud chooses eligible work and Kubernetes chooses node placement.
- [x] **ADR-0002 Durable State & Transactional Outbox:** States that PostgreSQL owns truth and NATS only wakes processing up.
  - Describes periodic reconciliation scan repairing lost broker notifications without erasing accepted work.
- [x] **ADR-0003 Delivery Semantics & Idempotent Execution:** States at-least-once delivery with idempotent control-plane transitions explicitly.
  - Rejects exactly-once claims; mandates workload tolerance for duplicate startup; distinguishes application retries from broker redeliveries.
- [x] **ADR-0004 Trust Model & Tenant Isolation:** Documents v1 posture: invited users, reviewed image allowlist, single cluster.
  - Explicitly states the limits (what v1 does NOT defend against) and confirms a namespace is a management boundary, not a hostile-code sandbox.
  - Documents foreign key cascading semantics (10 tenant tables with `ON DELETE CASCADE`, `audit_events` with `ON DELETE SET NULL`, `consumed_events` deduplication ledger).
  - Documents synchronous image allowlist policy check and `IMAGE_POLICY_VIOLATION` 422 error contract.

### Initial Schema & Migrations
- [x] Unique constraint on `(workspace, endpoint, idempotency_key)`, plus stored request-body hash (`uq_idempotency_records_workspace_endpoint_key`).
- [x] Unique consumed-event record per handler (`(event_id, handler)` on `consumed_events`).
- [x] Logical job state stored separately from attempt state (`jobs.state` vs. `job_attempts.state`).
- [x] `lease_epoch` present on intent and attempt; `resource_uid` present for Kubernetes object binding.
- [x] Foreign keys and workspace scoping on all 10 tenant tables.
- [x] Outbox table with event ID, schema version, and publish status.
- [x] Quota reservation table with reservation ID, expiry, and release status.
- [x] One migration owner named: Python Alembic owns shared schema (`migrations/versions/0001_baseline_schema.py`, `0002_close_schema_gaps.py`, `0003_add_recovery_pending_state.py`).

### API Contract Examples

## 3. Remaining Limitations and Open Questions

1. **Development Seam:** Caller identity in development mode relies on `X-Dev-Subject` header (Decision D1). Full OIDC token verification lands in Phase 1 (M1) using Keycloak.
2. **Adversarial Tenant Sandboxing:** Kubernetes namespace isolation is enforced via RBAC and PostgreSQL scoping; adversarial multi-tenant kernel escape testing is deferred to Milestone M4.
3. **Race Detector on Local Windows:** GCC fails with spaces in Windows paths (`C:\Users\pc city`); Go race detection is validated exclusively on Ubuntu runners in CI (`go test -race ./...`).
