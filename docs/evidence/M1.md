# Progress Note: M1 — First Live Application (In Progress)

- **Milestone ID:** `M1`

- **Document Date:** 2026-09-26
- **Environment:** Local development host (Windows 11 x64, Python 3.12/3.14, Go 1.23, PostgreSQL 16, Redis 7.2, NATS 2.10, Keycloak 24.0.5)

---

## 1. Scope and Implementation Reality

This document records the progress toward Milestone M1. As identified during engineering review, the current implementation is a development-only prototype and **does not meet the Roadmap exit criteria for M1 closure**:

1. **No Kubernetes Integration:** There is currently no Kubernetes client, no Kubernetes manifests or controllers, and no cluster-level Deployment, Service, or Ingress routing.
2. **No Container Isolation:** Workloads do not run in containers. The image catalog policy validates approved registry references at the API layer, but no container engine (Docker, Podman, containerd, or Kubernetes) is invoked.
3. **Local Host Probing:** Service "deployment" does not deploy or schedule a container; the reconciler (`HTTPProbeRunner`) merely executes HTTP GET requests against `127.0.0.1:{port}{health_path}` on the host machine.
4. **NATS JetStream Listener Implemented:** The Go runtime event listener (`runtime/internal/bus`) subscribes to JetStream event topics (`job.*`, `app.*`, `workload.*`) for immediate scheduler and executor wakeups with graceful fallback to periodic DB polling.
5. **No Live Recorded Demos:** The required duplicate submission and worker restart failure demos have not yet been recorded.

Consequently, **Milestone M1 remains OPEN in `MASTER-PLAN.md`**.

---

## 2. Implemented Capabilities (Development Baseline)

The following building blocks have been implemented for early validation:

- **OIDC Token Authentication:** Keycloak OIDC JWT Bearer token authentication with JWKS caching and RS256 verification in `apps/api/app/core/auth.py`.
- **Approved Image Catalog Policy:** Registry allowlist validation on deployment submissions, returning HTTP 422 for unapproved registries.
- **Application Endpoints:** Cursor-paginated application listing (`GET /v1/workspaces/{ws}/apps`) and inspection (`GET /v1/apps/{app}`) (pending owner Roadmap approval).
- **Transactional Outbox Dispatcher:** Background publisher draining unpublished outbox events to NATS JetStream with deduplication headers.
- **NATS JetStream Event Listener:** Go runtime `EventListener` (`runtime/internal/bus`) subscribing to admission and workload events with non-blocking wakeups (`Wake()`) on `Scheduler` and `Executor`, with graceful fallback to periodic DB polling.
- **Service Reconciler Prototype:** Go-based intent claiming and HTTP readiness checking via `HTTPProbeRunner` (restricted to `ENVIRONMENT=development`).
- **Dashboard UI Prototype:** React + Vite single-page application in `apps/web` providing workspace navigation and status polling.
