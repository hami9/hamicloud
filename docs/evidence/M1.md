## 2. Implemented Components & Deliverables

1. **OIDC Token Authentication (`apps/api/app/core/auth.py`):**
   - Implemented Keycloak OIDC JWT Bearer token authentication with remote JWKS caching and RS256 verification.
   - Dual-mode support: strict Bearer JWT in production, with authorized mock subject fallback in `ENVIRONMENT=development`.
2. **Approved Image Catalog Policy (`apps/api/app/api/v1/apps.py`):**
   - Registry allowlist validation rejecting non-approved image sources with HTTP 422 `IMAGE_POLICY_VIOLATION` envelope.
3. **Application Endpoints (`apps/api/app/api/v1/apps.py`, `workspaces.py`):**
   - Cursor-paginated application listing (`GET /v1/workspaces/{ws}/apps`) and application inspection (`GET /v1/apps/{app}`).
   - Deployment submission (`POST /v1/apps/{app}/deployments`) and single-click rollbacks (`POST /v1/apps/{app}/rollbacks`).
4. **Transactional Outbox & Event-Driven Wakeups:**
   - Background dispatcher draining PostgreSQL `outbox` records to NATS JetStream topics (`workload.service.deployed`).
   - Go runtime `bus.EventListener` (`runtime/internal/bus`) receiving notifications and triggering immediate non-blocking reconciler execution (`reconciler.Wake()`), with automatic periodic DB polling fallback.
5. **Kubernetes Workload Runner (`runtime/internal/reconciler/kube_runner.go`):**
   - Implemented `KubeWorkloadRunner` satisfying `WorkloadRunner` interface.
   - Constructs deterministic Kubernetes `apps/v1.Deployment`, `core/v1.Service`, and `networking/v1.Ingress` objects.
   - Probes pod and deployment readiness conditions, reporting detailed diagnostic errors.
   - Environment-safe: auto-detects in-cluster or kubeconfig credentials; falls back to `HTTPProbeRunner` in local development.
6. **Minimalist Web Dashboard (`apps/web`):**
   - Built following UI UX Pro Max minimalist principles with a strict 4-color palette:
     - **White Canvas & Elevated Cards (`#ffffff`, `#f8fafc`):** High contrast, crisp borders, subtle elevation.
     - **Royal Blue (`#2563eb`, `#1d4ed8`):** Primary interactions, active tab selections, focus outlines, live URL links.
     - **Emerald Green (`#10b981`, `#059669`):** Serving/Healthy status pills, live ingress pulse indicator, active pods.
     - **Warm Espresso / Bronze Brown (`#78350f`, `#92400e`, `#fef3c7`):** Readiness probe warning callouts, maintenance notices, rollback triggers.
   - Live Ingress URL Card with click-through and health indicator.
   - Dedicated readiness probe alert box for transparent error diagnostics.
   - Release history table with single-click rollback button.

2. **Build Isolation:** Workloads in M1/M2 deploy pre-built container images from approved registries. Automatic git repository builds (Source-to-URL) are scheduled for Milestone M3.
3. **Ingress URL Reporting:** While the dashboard UI checks `config_json.ingress_url` to render the live URL card, the current runtime does not write `config_json.ingress_url` to the database. Dynamic ingress persistence will be added when live Kubernetes ingress status reporting is integrated.
