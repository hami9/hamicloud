## 2. Implemented Architecture & Components

1. **Kubernetes Task & Workload Runners (`runtime/internal/reconciler/kube_runner.go`):**
   - `KubeWorkloadRunner`: Generates `apps/v1.Deployment`, `core/v1.Service`, `networking/v1.Ingress` resources with RFC 1123 label sanitization and readiness inspection.
   - `KubeJobTaskRunner`: Generates `batch/v1.Job` resources, watches completion, captures pod logs into artifacts directory, and cleans up finished pods.
2. **PostgreSQL Lease Fencing & Self-Healing Store (`runtime/internal/store/postgres.go`):**
   - Monotonic lease epochs fence off crashed workers.
   - `RecoverExpiredJobIntents` audits abandoned worker attempts and transitions eligible jobs into retry backoff loops.
3. **Deterministic State Machine & Scheduler (`runtime/internal/scheduler/scheduler.go`):**
   - Enforces finite retry budgets (`max_retries`) and backoff requeuing.
4. **Minimalist Responsive Dashboard (`apps/web`):**
   - High-contrast, WCAG AA accessible UI adhering to UI UX Pro Max guidelines.
   - Strict 4-color palette: White surfaces, Royal Blue primary interactions, Emerald Green health badges, and Warm Espresso retry/warning callouts.
