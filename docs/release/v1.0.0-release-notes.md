# HamiCloud v1.0.0 Release Notes

**Release Date:** 2026-10-20  
**Version:** `1.0.0`  
**Status:** Production-Ready Single-Tenant Cloud Runtime & Orchestration Platform

---

## 1. Overview

HamiCloud `v1.0.0` delivers a complete single-tenant PaaS and container orchestration platform combining a Python/FastAPI control plane, a Go runtime scheduler and Kubernetes executor, a transactional PostgreSQL + NATS JetStream + Redis Lease state synchronization fabric, Rootless BuildKit image builders, S3/MinIO durable log archival, and a Next.js 15 operator console.

---

## 2. Capabilities Delivered Across M0–M6

### Control Plane API (`apps/api` — Python 3.12 / FastAPI / SQLAlchemy 2.0)
- **Authentication & RBAC (M0, M4):** OIDC JWT validation (Keycloak RS256 JWKS) with workspace-scoped role enforcement (`admin`, `developer`, `viewer`) and cross-workspace isolation.
- **Transactional Outbox & State Machine (M0, M1, M3):** Every state-mutating request (`BUILD_ARTIFACT`, `DEPLOY_RELEASE`, `ROLLBACK_RELEASE`, `DISPATCH_JOB`) atomically writes domain state, an `OperationRecord`, an immutable `AuditEvent`, and an `OutboxMessage` within a single PostgreSQL transaction (`Idempotency-Key` enforced).
- **Workspace Quotas & Admission Control (M2, M4):** Hard admission checks against CPU (`millicores`), memory (`MB`), storage (`MB`), and maximum concurrent jobs (`max_concurrent_jobs`), synchronized with Kubernetes `ResourceQuota` and `LimitRange` manifests.
- **Write-Only Envelope-Encrypted Secrets (M4):** Workspace secrets encrypted at rest using AES-256-GCM envelope encryption (`HKDF-SHA256` per-workspace DEK derivation). Plaintext values are never returned by `GET` or `LIST` endpoints and are scrubbed from build/job log streams.
- **Prometheus Metrics & Workspace Telemetry (M5):** `/metrics` endpoint exposing HTTP latency histograms, operation transition counters, workspace resource saturation gauges, and build/rollback duration histograms, paired with `GET /v1/workspaces/{id}/telemetry`.

### Runtime Engine (`runtime` — Go 1.23 / client-go)
- **Outbox Relay & NATS JetStream Consumer:** Polls unpublished `outbox_messages`, publishes to NATS JetStream with deduplication headers, and dispatches reconciliation work.
- **Redis Lease Fencing:** Acquires distributed per-resource Redis leases (`SET NX PX`) with monotonic fencing tokens and Lua ownership renewal/release scripts before mutating Kubernetes resources.
- **Kubernetes Reconciler:** Translates HamiCloud `Deployment`, `Release`, and `JobExecution` specs into hardened Kubernetes `Namespace`, `ResourceQuota`, `LimitRange`, `NetworkPolicy`, `Secret`, `Deployment`, `Service`, `Ingress`, and `batch/v1.Job` objects.
- **Canary Rollouts & Automatic Rollback (M3):** Orchestrates weighted canary traffic shifts (`10% -> 50% -> 100%`) and one-click/automatic rollback to the prior `ACTIVE` release upon health-check failure.
- **Rootless BuildKit & S3 Log Archiver (M1, M2):** Executes container builds from source contexts, pushes immutable `@sha256:...` images to the internal OCI registry, streams real-time container logs, and archives gzipped log bundles to MinIO/S3.

### Operator Console (`apps/web` — Next.js 15 / React 19)
- Unified dashboard for Workspaces, Services, Releases & Rollbacks, Finite Jobs, Live/Archived Logs, Write-Only Secrets, Audit Events, and Quota Utilization bars.

### Packaging & Operations (`deploy/helm/hamicloud`, `deploy/observability`, `docs/runbooks`)
- Production Helm v2 chart (`deploy/helm/hamicloud`, version `1.0.0`) with digest-pinned images and `restricted` PodSecurity contexts.
- Prometheus alert rules (`deploy/observability/alerts.yml`), Grafana dashboard (`deploy/observability/grafana-dashboard.json`), and five operational runbooks (`docs/runbooks/`).
